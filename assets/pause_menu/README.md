# Editable pause-menu overlay

The transparent 1280 x 720 overlay is `pause_menu.png`. Edit that file in
an image editor to change the pause screen. The game draws it over the dimmed arena but behind the live
"PAUSED" title, menu options, selection highlight, and resume hint. Without
`pause_menu.png`, the pause screen is unchanged.

Transparent pixels show the dimmed gameplay scene. The template frames the
title and option list; keep those areas clear of detailed art so the live
text and selection remain readable. The game resizes other image dimensions
to 1280 x 720.
